Keys you press appear here
Press RESET to wake the monitor.

Key in a program

Reset→Ex Mem→2000→Next

The display now shows address 2000 and whatever byte is stored there. Type two hex digits for the opcode, press NEXT to store it and move to 2001, and carry on. Press RESET when the last byte is in.

Read a location back

Ex Mem→2052→Next

This is how you read your answer after running a program. NEXT steps forward through memory, PREV steps back. Nothing is written unless you type new digits.

Run the program

Reset→Go→2000→Exec

The display goes blank while the processor runs and comes back when it reaches HLT. If it never comes back, your program is stuck in a loop — press RESET.

Single-step through it

Go→2000→SIthenSI

Each SI executes one instruction and shows the next address with the opcode sitting there. Use Ex Reg in between to see what the registers did.

Examine registers

Ex Reg→Aor8(H)→Next

The small legend under each hex key is its register name in this mode: A B C D E F on keys A–F, H on 8, L on 9, SP on 0, PC on 1. NEXT cycles to the following register.

Your keyboard works too

0–9, A–F are the hex keys. Enter = NEXT, Backspace = PREV, Esc = RESET, M = EX MEM, R = EX REG, G = GO, X = EXEC, S = SI.

Labels differ between kits. Vinytics and Dyna boards say EXMEM / EXREG; ALS and ESA boards say SUBST MEM / REG, and the execute key may be marked FILL, EXEC or GO again. The sequence is the same everywhere: command key, address, confirm. Check the legend printed on your kit before you start.

Your real kit shows you six digits and nothing else. This panel is here so you can see what the processor is actually doing while you learn the key sequences — treat it as training wheels.
