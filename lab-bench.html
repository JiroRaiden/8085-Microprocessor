Reading the flag column. Only the letters shown are modified. INR and DCR touch every flag except CY — that is the classic viva question. DAD touches only CY. MOV, MVI, LDA, STA, LXI and the jumps touch none.

Writing a line

LOOP:   MVI  C, 05H     ; label, op, operands
        LXI  H, 2050H
        JNZ  LOOP

A label ends in a colon. Everything after ; is a comment. Operands are separated by a comma.

Numbers

  • 2050H hex — must start with a digit, so write 0FFH, not FFH
  • 10110010B binary
  • 25 decimal, 'A' character
  • LOOP+2 label arithmetic

Directives

  • ORG 2000H — set the load address
  • DB 05H, 'A' — place bytes
  • DW 2050H — place a word, low byte first
  • DS 8 — reserve bytes
  • COUNT EQU 0AH — name a constant
  • END — stop assembling

Bench habits that save marks

  • End every program with HLT or RST 3 — both stop the run here.
  • Initialise SP with LXI SP, … before any CALL or PUSH.
  • A counter loaded with 00H runs 256 times, not zero. Guard it.
  • RRC is safe for bit counting; RAR drags the old carry in.
  • Type input bytes straight into the memory grid, then Run.
